# Coffee Shop Sales Analysis using Power BI

## Project Overview

This project focuses on analysing coffee shop sales data using Microsoft Power BI to identify sales trends, customer purchasing patterns, and product performance.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX

## Dataset Overview

- Total Records: 149,116
- Total Columns: 11
- Transaction ID
- Transaction Date
- Transaction Time
- Transaction Quantity
- Store ID
- Store Location
- Product ID
- Unit Price
- Product Category
- Product Type
- Product Detail

## Key Performance Indicators (KPIs)

- Total Sales: 698.81K
- Total Transactions: 149.12K
- Total Quantity Sold: 218.14K

## Business Questions

1. What are the total sales and transactions?
2. Which product categories generate the highest sales?
3. Which product types contribute most to revenue?
4. Which days of the week have the highest sales?
5. How do sales vary across different store locations?
6. What are the overall sales trends?
